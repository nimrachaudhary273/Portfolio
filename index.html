01 — about me

Background

Frontend developer with professional experience building responsive, user-friendly web interfaces using HTML, CSS, and JavaScript. I'm experienced in translating Figma and Adobe XD designs into high-quality, pixel-focused implementations, and comfortable working with WordPress, Bootstrap, and Tailwind CSS alongside designers, backend developers, and product teams.

I care most about the last 10% of a build: the state that shows up only on a slow connection, the layout that only breaks at 813px, the button that needs a focus ring. That attention is what separates a page that looks done from one that's actually ready to ship.
